# Manual deployment dependencies

These files are intentionally outside the Connect app ZIP and require separate,
manual deployment:

- [`endpoint-scripts`](endpoint-scripts/README.md) contains the self-contained
  GUID collector BAT, screenshots, and Script Repository import instructions.
- [`groups`](groups/README.md) contains the Forescout group-tree export for
  manual import.

Importing or upgrading the Connect app does not install or update either item.
